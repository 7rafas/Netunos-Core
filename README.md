# Netuno's Core

**Agende o desligamento do seu computador de maneira simples, rápida e sem precisar decorar comandos.**

O **Netuno's Core** é um aplicativo para **Windows** que transforma o desligamento agendado em uma tarefa acessível. Em vez de recorrer ao terminal e memorizar comandos, você escolhe quando deseja desligar o PC diretamente em uma interface prática e intuitiva.

A ideia do projeto é **simplificar e divulgar uma funcionalidade útil do Windows** que nem todo mundo conhece — seja para deixar o computador concluir uma tarefa, evitar que ele permaneça ligado desnecessariamente ou organizar melhor seu tempo de uso.

---

## Funcionalidades

- **Desligamento rápido:** agende o desligamento com um clique usando os tempos de **30 minutos, 1 hora ou 2 horas**.
- **Tempo personalizado:** informe o número de minutos desejado para criar um agendamento sob medida.
- **Acompanhamento:** consulte na tela inicial o tempo restante até o desligamento.
- **Cancelamento imediato:** cancele um desligamento agendado pelo botão dedicado, sem utilizar comandos do sistema.
- **Logs e histórico:** acompanhe agendamentos e cancelamentos, com data, horário, duração e status. Também é possível limpar o histórico.
- **Atalhos personalizáveis:** ajuste os tempos dos três botões de desligamento rápido na aba **Configurações**.
- **Atalho de teclado:** personalize a combinação usada para fechar o aplicativo. Por padrão, é **Ctrl + Q**.
- **Dicas integradas:** consulte orientações de uso e configure a exibição automática das dicas ao iniciar o programa.

## Como usar

1. Acesse a seção **Releases** deste repositório e baixe a versão de sua preferência.
2. Abra o **Netuno's Core**.
3. Na tela inicial, escolha um dos atalhos ou defina um tempo personalizado em minutos.
4. Confira o tempo restante até o desligamento na própria interface.
5. Se mudar de ideia, utilize **Cancelar o desligamento**.

> [!IMPORTANT]
> Salve seus arquivos antes do horário escolhido. **Fechar o Netuno's Core não é o mesmo que cancelar um desligamento agendado.** Para interromper o agendamento, use a opção específica de cancelamento.

## Identidade visual

A identidade visual do Netuno's Core foi inspirada em **Rei Ayanami**, de *Neon Genesis Evangelion*. A paleta azul e a estética do aplicativo refletem essa referência, escolhida por preferência pessoal durante o desenvolvimento.

> Este é um projeto independente, sem vínculo ou afiliação oficial com *Neon Genesis Evangelion*.
